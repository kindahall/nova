# Nova OS Web Space — Codex Starter Kit

This repository package contains the blueprint and visual references for building the first interactive **Nova OS Web Space** prototype.

Nova OS is a premium AI-native desktop experience that transforms user intentions into workspaces, software and automations.

## How to use this with Codex

1. Create a new GitHub repository, for example:

```txt
nova-os-webspace
```

2. Upload this kit into the repository.

3. Make sure Codex reads:

```txt
AGENTS.md
plan.md
images/
```

4. Start with the master prompt in `prompt_master_codex.md`.

## First build objective

The first build should create a web prototype with:

- Nova OS desktop shell;
- Nova Rail;
- top Nova Command pill;
- bottom Activity Shelf;
- My Space window;
- Personalize window;
- onboarding flow;
- Nova Command;
- app creation flow;
- generated CRM app demo.

## Product principle

Do not build a normal dashboard.

Build something that feels like a **new operating system experience**.
